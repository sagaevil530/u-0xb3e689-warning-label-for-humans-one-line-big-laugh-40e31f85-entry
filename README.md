One line, one safety warning label that should come printed on every human being:

> WARNING: This human skipped the instructions, blamed the instructions, and will now explain them to you.

`main.py` (Python 3.13, standard library only) writes that line, exactly as-is, to `/output/entry.txt` as UTF-8 text. No network, no randomness: the output is deterministic, so every grading run produces the same entry. A length guard keeps the line inside the 1–160 character gate.

## Run it

```sh
python3 main.py
```
